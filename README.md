# mobile-privacy

Публичная политика конфиденциальности для мобильных приложений и игр Владимира Верхова.

Страница: https://verhovv.github.io/mobile-privacy/

Один документ используется для всех приложений с одинаковым набором SDK (Yandex Mobile Ads / РСЯ) и локальными сохранениями. Русская версия открывается по умолчанию, английская — по кнопке или по якорю `#rights-en`.

## Ссылки для AppGallery

- URL-адрес политики конфиденциальности: `https://verhovv.github.io/mobile-privacy/`
- URL-адрес прав субъекта персональных данных: `https://verhovv.github.io/mobile-privacy/#rights`

Оба адреса ведут на один документ. Второй открывает раздел 6 «Права субъекта персональных данных».

## Публикация

Репозиторий должен быть публичным: GitHub Pages для приватных репозиториев требует платного плана.

1. Создать публичный репозиторий `mobile-privacy` без README и лицензии.
2. Отправить содержимое:

   ```sh
   git remote add origin git@github.com:verhovv/mobile-privacy.git
   git branch -M main
   git push -u origin main
   ```

3. В настройках репозитория: **Settings → Pages → Build and deployment → Source: Deploy from a branch**, ветка `main`, папка `/ (root)`, сохранить.
4. Дождаться сборки и открыть `https://verhovv.github.io/mobile-privacy/`.

Файл `.nojekyll` отключает обработку Jekyll, чтобы GitHub Pages отдавал страницу как есть.

## Обновление

Правки вносятся в `index.html` и отправляются в `main`. Pages пересобирается автоматически, обычно в течение минуты.

При изменении набора данных, SDK или рекламного партнёра документ нужно обновить, а в AppGallery — привести в соответствие Privacy Label / Data security.

## Проверка перед отправкой в магазин

- Страница открывается по HTTPS без авторизации.
- Обе ссылки из карточки приложения работают.
- Указаны оператор, email и страна.
- Список данных совпадает с фактическим поведением приложения.
- Дата последнего обновления актуальна.
